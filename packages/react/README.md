# @calendrix/react

React adapter for [calendrix](../../README.md): hooks and components for an accessible date and time picker with Persian (Jalali) and Gregorian support.

> Pre-alpha. See the [roadmap](../../docs/roadmap.md) for what is implemented.

```bash
pnpm add @calendrix/react @calendrix/core
```

Peer dependencies: `react` and `react-dom` 18 or newer.
